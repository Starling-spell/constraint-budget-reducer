# Security

Experimental; not audited. Report vulnerabilities privately to the repository maintainer. No funds are held or moved. Consensus checks semantic equivalence, not real-world truth or legal correctness. Malformed output and validator disagreement do not publish a compact artifact. Immutable inputs remain available after successful and rejected attempts.

An attacker may embed instructions in data; prompts delimit data and independent validators audit against original clauses. This reduces but does not eliminate shared-model or injection risk. Consumers must bind the exact original input root and must not treat a compacted result as authorization.
